# Nexus — Interactive Landing Page

An animation-driven landing page recreation built with React, Tailwind CSS, and GSAP. This project explores modern frontend techniques, including pinned sections, scroll-linked animations, and interactive navigation.

## Overview

Nexus is a frontend practice project recreated from a website design found on [TemplateMo](https://templatemo.com/). The goal was to study and implement the visual layout, transitions, and interactive behaviour of the original design while strengthening my skills in React and animation-driven web development.

## Features

- Responsive landing page layout
- Scroll-triggered animations using GSAP and ScrollTrigger
- Pinned sections and layered scrolling effects
- Scroll-linked section navigation
- Interactive content sections
- Smooth transitions and visual effects

## Built With

- React
- Vite
- Tailwind CSS
- GSAP
- GSAP ScrollTrigger
- @gsap/react
- Lucide React

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Sultan-Aleem/Nexuss_landing.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Nexuss_landing
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
